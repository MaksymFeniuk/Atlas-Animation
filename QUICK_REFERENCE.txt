🎨 CUSTOMIZATION
═══════════════════════════════════════════════════════════════

Change Colors:
  → Edit: tailwind.config.ts
  → Find: colors object
  → Modify: dark-900, accent-500, etc.

Add Animations:
  → Edit: src/app/page.tsx
  → Find: SAMPLE_ANIMATIONS array
  → Add new objects with id, title, category, etc.

Change Layout:
  → Edit: src/app/page.tsx
  → Find: grid classes (grid-cols-1, lg:grid-cols-3)
  → Adjust column numbers


🎬 ANIMATION TYPES
═══════════════════════════════════════════════════════════════

Fade      Opacity changes (0 ↔ 1)
Slide     Position changes (X axis)
Scale     Size changes (1 ↔ 1.2)
Morph     Border radius changes
Rotate    Rotation changes (0° ↔ 360°)


🔄 FILTER OPTIONS
═══════════════════════════════════════════════════════════════

Motion Behavior:      Fade, Slide, Scale, Morph, Rotate
Interaction Pattern:  Hover, Scroll, Entrance, Exit, Loop
Visual Character:     Minimal, Organic, Geometric, Abstract, Sharp


📱 RESPONSIVE BREAKPOINTS
═══════════════════════════════════════════════════════════════

Mobile       < 768px     (1 column, drawer menu)
Tablet       768-1024px  (2 columns, sidebar)
Desktop      > 1024px    (3 columns, full sidebar)
