🚀 SETUP EXPLAINED
==================

When you run "npm run setup", it will:

1. Create proper directory structure:
   - src/
   - src/app/
   - src/components/
   - public/

2. Move files to correct locations:
   - layout.tsx → src/app/layout.tsx
   - page.tsx → src/app/page.tsx
   - globals.css → src/app/globals.css

3. Install dependencies:
   - React, Next.js, Framer Motion, Tailwind CSS, etc.

This ensures your Next.js project has the correct App Router structure.

❓ TROUBLESHOOTING
==================

Q: I get "Cannot find module 'next'"
A: Run "npm install" from project root

Q: Port 3000 is already in use
A: Run "npm run dev -- -p 3001" to use port 3001

Q: Files are in wrong location
A: Run "npm run setup" to organize them

Q: Styles are not loading
A: Make sure globals.css is in src/app/, then clear .next folder

Q: TypeScript errors
A: Make sure all app files are in src/app/ directory

For more help, see INSTALLATION.md
